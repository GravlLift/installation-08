This project is licensed under the GNU Affero General Public License, version 3. It builds on JGtm's LevelUp project and published halo-infinite-film-decoder, halo-infinite-map-images, halo-infinite-files-reader, and halo-api modules. See `third_party/README.md` and the upstream license and notice files for provenance.

The files-reader module includes the GPL-3.0 `ooz` decompressor; see `third_party/files-reader/ooz/NOTICE.md`. No game assets are distributed. Game-derived assets (map meshes) are built from the user's own installation.

`internal/mapmesh`, `internal/meshbuild` and `internal/mapref` are adapted from LevelUp's `internal/mapmesh` and `cmd/mapmesh-build` (AGPL-3.0, JGtm), rewritten to resolve and build a map mesh, a variant's object layer, a weapon model, the Spartan body, a single armor piece and a weapon's first-person rig in-process instead of through a child process and its own wire protocol. `internal/mapref` embeds reference data copied unmodified from LevelUp's `data/titles/halo_infinite/reference/` (the objectives catalog, the per-map background sidecars, the per-map geometry settings, the Forge material tints catalog `forge_materials.json` ~164 KB, and the Forge object visibility catalog `forge_objects.json` ~3.8 MB): measurements and catalogs built from publicly downloadable UGC map variants, not extracted from a local game installation. The variant builder's `--forge-materials` and `--forge-objects` flags override these embedded defaults with a different file when given; they are optional precisely because the defaults are shipped in the binary.

`internal/mapmesh/spartan.go`'s `BodyAnimations` list is copied from LevelUp's `internal/mapmesh/meshproto` (`animationsDuCorps`, the body-only prefix of its `AnimationsSpartan`): names are the game's own animation identifiers, not game assets. Armor piece coatings (the community Ekur reference, a Blender plugin's JSON export external to both LevelUp and this repo) and the per-weapon third-person reload/fire animation catalog are not ported; see README.md's build-piece and build-spartan sections.
